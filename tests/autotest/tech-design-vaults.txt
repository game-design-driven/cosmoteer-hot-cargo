# Spec 441, 1016, 1541: vaults built into each vanilla starter design: the vaults for the starting tech inside the hull, crew paths kept.
# A bay that a vault takes goes outside the hull, so every design keeps its storage. After the power-up time the ship still matches its blueprint, so the saved picture shows the ship. Headless, no save.
newgame run
wait 8
vaultbuild vanilla 0
expect vaultsbuiltindesign == vaultsneeded
expect storagekept == 1
expect designmatches == 1
vaultbuild vanilla 1
expect vaultsbuiltindesign == vaultsneeded
expect designmatches == 1
vaultbuild vanilla 2
expect vaultsbuiltindesign == vaultsneeded
expect designmatches == 1
vaultbuild vanilla 3
expect vaultsbuiltindesign == vaultsneeded
expect designmatches == 1
# No vault may go on a storage bay: each grabbed bay goes back, and the hull has no other 2x2 room, so the design stays as it was.
vaultbuild vanilla 0 nobay
expect vaultsbuiltindesign == 0
expect vaultnoroom == 1
quit
