# A vanilla starter (no vault) may start too: its tech starts in normal storage and decays.
shipcheck preset 0

expect shipvaulttech >= 8
shipcheck preset 1
expect shiplegal == 1
expect shipvaulttech >= 8
shipcheck preset 2
expect shiplegal == 1
expect shipvaulttech >= 8
shipcheck preset 3
expect shiplegal == 1
expect shipvaulttech >= 8
shipcheck vanilla 0

expect shipvaulttech == 0
