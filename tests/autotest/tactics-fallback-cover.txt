# Fall back in cover (spec 1305, 1306): a damaged pirate cargo ship that carries the resources hides behind a rock and repairs.
newgame
wait 8
ev_set Enabled false
# A quiet world: no scavengers or Wayfarers arrive, and nearby enemies are cleared before the test ships spawn, so no other
# fight keeps the ship from repairing.
scav_set Enabled false
fr_set PayForwardChance 0
godmode on
# The player ship must not shoot the damaged ship: its crew died, and it turned into a wreck in cover (#377), as in tactics-fallback-pool.
playerweapons off
tacticlog on
aiset FleeOnVanilla false
aiset RegroupOnVanilla false
aiset CallOnVanilla false
aiset CoverEnabled false
aiset BaitEnabled false
aiset TeamEnabled false
aijitter 0
aitrait Pirate Raiders FallBack 1
aitrait Pirate Ambushers FallBack 1
# A big cargo ship repairs slowly: give the crew time. The plan and the hiding spot are the checks.
aiset FallBackMaxSeconds 600
openspace 6000
airocks 6 900
fr_kill_enemies
# A pinned hull: the random pick uses the sim random stream (#277 moved it), and some hulls never repair in cover in time.
aispawn pirates 1 3 trade hull=Gannet
wait 3
# Well inside the Gannet's radar (1,362). aispawn puts it about 1,360 away, and when the player ship was just off its radar, it saw
# no threat, had no rock to hide behind, and fell back Away (#377, CI jitter seed 2136). +X has a rock of the ring between them.

aigivelacking 0 0

waitfor ai_fb_in_cover >= 1 90
waitfor ai_fb_active == 0 400
