# Off the Books through the real comms window (spec 1801 to 1809): the station line opens the quote; the meet spawns a fence away from the
# station; the crates go over in the fence's comms. A clean sale, a sting, "Changed my mind" and a fence that leaves.
newgame run
wait 8
ev_set StationEventChance 0
ev_set ArrivalEventChance 0
ev_set CourierChance 0
ev_set CooldownSeconds 0
godmode on
ev_tostation
save offbooks
# 1. Changed my mind: the page closes with no change and no meet. The station's line is used up (spec 769).
ev_open station
ev_click station Sell crates off the books
expectevent off_books
# Spec 816: the window is on the screen and shows the whole page or its scroll bar.
expect comms_fit == 1
ev_mark
ev_click station Changed my mind
expect ev_pending == 0
expect ev_tech_gain == 0
expect ev_money_gain == 0
expect ob_meet == 0
dip_close
# The line is used up for this station (spec 769), so the next steps start from the save.
load offbooks
wait 3
# 2. A clean sale (no risk): the meet spawns the fence and a log mission; one crate goes over at the quote, and heat falls.
ev_set OffBooksRiskBase 0
ev_set OffBooksRiskPerHeat 0
ev_set OffBooksRiskPerCorporate 0
ev_open station
ev_click station Sell crates off the books
ev_click station Set up the meet
expect ob_meet == 1
expect ob_fence >= 0
expect ob_price > 0
dip_close
ev_contact_goto
pause off
ev_contact_goto
pause off
waitfor ob_fence == 1 20
ev_open contact
ev_click contact Hand over the crates
expectevent off_books_meet
ev_mark
pick 1
expectoption 1 selected
ev_click contact Hand them over
expect ev_tech_gain == -1
expect ev_money_gain == ob_last_price
expect ev_heat_gain < 0
expect ob_meet == 0
# 3. A sting (sure risk): paid, but heat rises and corporate ships jump in.
load offbooks
wait 3
ev_set OffBooksRiskBase 1
ev_set OffBooksRiskCap 1
ev_open station
ev_click station Sell crates off the books
ev_click station Set up the meet
dip_close
ev_contact_goto
pause off
ev_contact_goto
pause off
waitfor ob_fence == 1 20
ev_open contact
ev_click contact Hand over the crates
ev_mark
pick 1
ev_click contact Hand them over
expect ev_tech_gain == -1
expect ev_money_gain > 0
expect ev_heat_gain > 0
expecttagged hc_ev_corp >= 1
# 4. A save and a load keep the meet (spec 1808). The fence leaves after its time, and the meet is off.
load offbooks
wait 3
ev_set OffBooksMeetSeconds 15
ev_open station
ev_click station Sell crates off the books
ev_click station Set up the meet
expect ob_meet == 1
dip_close
save offbooks_meet
load offbooks_meet
wait 3
expect ob_meet == 1
pause off
waitfor ob_meet == 0 20
quit
