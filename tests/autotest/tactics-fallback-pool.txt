# Fall back to a faction mate (spec 1305, 1307): a damaged Monolith combat ship without resources or storage flies next to a
# Monolith trade ship (another player index of the same faction) that holds them, and repairs from the shared pool.
newgame run
wait 8
ev_set Enabled false
# A quiet world: no scavengers or Wayfarers arrive, and nearby enemies are cleared before the test ships spawn, so no other
# fight keeps the ship from repairing.
scav_set Enabled false
fr_set PayForwardChance 0
# The test ship fights the player ship; one-hit part losses made it derelict and ended the fight early (#184).
godmode full
# The player ship must not shoot the damaged ship: one hit on its weak control room makes it a wreck.
playerweapons off
tacticlog on
aiset FleeOnVanilla false
aiset RegroupOnVanilla false
aiset CallOnVanilla false
aiset CoverEnabled false
aiset BaitEnabled false
aiset TeamEnabled false
aijitter 0
aitrait Monolith Phalanx FallBack 1
aitrait Monolith Lancers FallBack 1
aiset FallBackTripSeconds 600
openspace 6000
# Roaming pirates would attack the player ship; a lost player ship sends every AI ship into stasis.
fr_kill_enemies
# A fixed hull, so the test world and its rolls stay the same. With the random pick (an Iota on Linux CI) a ship of a third side
# shot the test ship during its repair; aialone now removes such ships too (#188).
aispawn monolith 1 1 hull=Cartridge
aispawn monolith 1 3 trade
# Every other ship of the test's sides and every other enemy of the players leave the system (#184): the patrols of the test
# world turned hostile with the test's war and fought the player ship.
aialone
# The faction mate starts beyond the vanilla pool range (400).
ainear 1 0 1500
# The player ship waits further away. It stays within the live area, because ships far from every player go into stasis.
ainew_watch 0 1800
wait 3
aistrip 0 resources
aidamage 0 0.3
aigivelacking 1 0
waitfor ai_fb_pool >= 1 30
# Its own storage is empty, so queued repairs and health gains come from the faction mate's stock (another player index).
waitfor ai_new_first_jobs >= 1 60
waitfor ai_fb_active == 0 400
expect ai_new_first_state == 2
expect ai_new_first_health >= 0.6
