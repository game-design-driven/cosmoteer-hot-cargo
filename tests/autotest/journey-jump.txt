# Journey: the Buyer appears on the first visit of the Buyer's system (spec 2554), through the real jump hook.
# Headless test slots do not draw frames, so the jump animation never ends and the sim stays paused after the switch.
# So this test checks only what the switch itself does. journey-run.txt checks trading with the Buyer.
