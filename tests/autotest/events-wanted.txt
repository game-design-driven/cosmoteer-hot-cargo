# Wanted and hunted (spec 470-472): the warning, the Wanted trigger and the events that clear vanilla wanted.
newgame
wait 8
ev_set WantedEventChance 1
# Wanted alone stays vanilla: no warning, no event. ("wanted" is the UX test command: the nearest station's faction wants you.)
# It runs next to a station: a station far from the fleet is not live (stasis), and a live trade ship is luck. The station must see
# the fleet once (wait 2), or vanilla drops the wanted faction at once; after that, wanted lasts its search time.
ev_tostation
wait 2
wanted
wait 2
# Fight in open space: a station's faction can take a side (the start station's owner changes with the system layout).
openspace 5000
wait 2
expect ev_wanted == 1
expect ev_wanted_warned == 0
expect ev_pending == 0
# Heat reaches the first stage: the warning fires and a Wanted event opens.
stage
# 5 heat above the stage: the crate payment below takes 5 heat, and the second warning needs the stage.
heat 5
wait 2
expect ev_wanted_warned == 1
expect ev_pending == 1
eventview
expectneed clean_record met
expectneed decoy_run met
# A Clean Record, paid with a crate: wanted clears.
event clean_record
pick 2
ev_mark
choose 1
expect ev_wanted == 0
expect ev_tech_gain == -1
wait 1
expect ev_wanted_warned == 0
expectneed decoy_run unmet
# Wanted again while hunted: the warning fires again. Decoy Run, paid in money: wanted clears. (A station again, as above.)
ev_tostation
wait 2
wanted
wait 2
openspace 5000
wait 2
expect ev_wanted_warned == 1
event decoy_run
ev_mark
choose 1 1
expect ev_wanted == 0
expect ev_money_gain < 0
quit
