## 5. Run structure and length

1. A run has `RunSectorCount` sectors (default 6): the steps from the start to the Buyer, both counted (requirement 2550). On the run map, the Buyer appears when the players first enter the Buyer's system, the one system at the end of the map (requirement 2554). On another map size, it appears when the players first enter a system with sector index `RunSectorCount` or more. Once per run. A mission in the log points to it, and a message shows it.
2. The mod adds the map size "Hot Cargo run" (`mod/journey/galaxy.rules`): the run map of section 73, a lens of systems in bands from the start to the Buyer, `RunSectorCount` − 1 jumps on a direct route. It is first in the map size list, so it is the default while the mod is on. The player can still choose Standard. A change of `RunSectorCount` applies to new runs only (requirement 2414).
3. The danger tier of a system follows its band on the run map (requirement 2552): tier 1 at the start, `FinalSectorTier` (default 12) at the Buyer, in even steps between. `FinalSectorTier` is a tunable that applies to new runs (requirement 2414).
4. Fame and money rewards are scaled by `RewardScale` (default 1.0, the vanilla rates). The scale multiplies the difficulty reward factors. So it applies to mission rewards, fame for defeated ships and the reward text in the UI. On the default Fast economy, six missions a sector pay about twice what a fleet needs to keep up with the tier ramp before `MissionMoneyScale`, and about three times with it (BALANCE.md, findings 1 and 11), so 1.0 is enough for the shorter run. The Normal and Slow economies make the run tighter. Mission money (not fame) is also × `MissionMoneyScale` (default 1.5): it makes up for the salvage cut (requirement 1247), so moving on to the next mission pays more than salvaging (BALANCE.md, finding 11). Only vanilla mission money rewards read it, the Hot Cargo missions too. Contract fees, event money (requirement 73), the Buyer and tech value do not change.
5. The new career screen keeps the vanilla difficulty options. The mod does not add its own difficulty screen. It adds one row: the co-op enemy scaling slider (requirement 330). The vanilla levels scale Hot Cargo's pressure (requirement 680).
